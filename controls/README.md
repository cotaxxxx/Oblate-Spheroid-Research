# Exact Expectations

The expectations in this directory are fixed independently of the future
production evaluator.

## Sphere positive expectation

```text
b_ob(1) = pi^2/32
        = 0.3084251375340424...
```

## Sphere symbolic identity

For `lambda = 1`, the numerator bracket in `gamma_t` must simplify to

```text
-mu*q - (1 - t*mu)*(t - mu) = -t*(1 - mu^2).
```

A future production evaluator must reproduce the exact expectation and an
interval enclosure containing the exact value. The expected value must never
be generated or overwritten by that evaluator.

An expectation becomes a control only when a test actually calls the
implementation and the expectation is not generated by that implementation.
Renaming a file or test does not perform this promotion.
